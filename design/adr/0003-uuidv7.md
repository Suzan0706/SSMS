# ADR 0003: UUIDv7 generated in the API

- **Status:** Accepted
- **Date:** 2026-10-22

## Context

Offline clients and bulk imports need ids before the database sees the row; random UUIDv4 fragments B-tree indexes.

## Decision

The API assigns UUIDv7 (48-bit millisecond time + random) when an object is constructed (`IdMixin` init event). `gen_random_uuid()` remains the database default for SQL scripts.

## Consequences

Related rows can reference each other before the flush; inserts are append-mostly. Ids reveal creation time to the millisecond, which is acceptable.

## Evidence

`app/core/ids.py`, `app/db/base.py`; `tests/test_core.py::test_uuid7_is_version_7_and_time_ordered`.
